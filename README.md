
# ML Based PDF Document Classifier

## Features
- PDF Text Extraction
- NLP Text Preprocessing
- TF-IDF Feature Extraction
- Machine Learning Classification
- Confidence Score
- CSV + JSON Output
- Error Logging

## Technologies
- Python
- pdfplumber
- NLTK
- Scikit-learn
- TF-IDF
- Naive Bayes

## Installation

pip install -r requirements.txt

## Train ML Model

python train_model.py

## Run Project

python main.py

## Output

Results stored in:
- output/results.csv
- output/results.json

- Invoice
- Contract
- Bank Statement
- Resume
- Report
